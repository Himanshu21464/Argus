Why a C++ kernel with autograd is non-negotiable.

10–100×
throughput penalty

Python wrappers cost an order of magnitude in the hot path. With 10⁷ forward calls per retrieval, that order of magnitude is a week on the cluster.

bit-exact
determinism

Biosignature claims need posteriors that are bit-reproducible across hardware and years. Python autograd toolchains drift; a C++ tape with explicit operators does not.

100 GB
opacity tables, on-device

HITRAN/HITEMP/ExoMol grids are 1–100 GB per molecule. Argus keeps them on the GPU across the entire retrieval — no host bounce.

∇ x
composability

The same RT primitive callable from MCMC, normalizing-flow posteriors, and gradient-based MAP — without rewriting.

2050+
vendor longevity

A 2026 telescope takes data until 2050+. The kernel that processes its photons must compile in 2050.

Python and Julia bindings live above the kernel — for retrieval scripts, agent reasoning, plotting, UI. The hot path is C++.

What ships in examples/01_transmission_spectrum.cpp today, M1.

argus@retrieval:~/examples cpp · 47 lines · gcc 15.2 · -Wall -Wpedantic -Wconversion 
// 1. Build a 40-layer isothermal H2O atmosphere.
using namespace argus;
Species h2o{"H2O", 18.015};
Atmosphere atm = isothermal(1200.0,    // T [K]
                            1.0e-6,     // P_top [bar]
                            1.0e2,      // P_bot [bar]
                            40,         // n_layers
                            h2o,
                            1.0e-3);    // VMR

// 2. Attach an opacity kernel.
// M2 swaps GreyOpacity for HITRAN+CUDA Voigt — call site unchanged.
auto opacity = std::make_shared<GreyOpacity>("H2O", 1.0e-22);

// 3. Forward model.
TransmissionModel model;
model.add_opacity(opacity);
Spectrum s = model.forward(atm, make_grid(2000.0, 4000.0, 21));

// 4. Argus IR — content-addressed reproducible runs.
ir::Graph g;
auto a = g.add(ir::NodeKind::kAtmosphere,    "atm");
auto o = g.add(ir::NodeKind::kOpacity,        "h2o_grey");
auto m = g.add(ir::NodeKind::kForwardModel,   "transmission", {a, o});
auto p = g.add(ir::NodeKind::kSpectrum,       "out", {m});

std::cout << g.content_address();      // → 845f876e00f4ea93

Mission timeline · 18 months · single workstation.

No telescope, no wet lab, no privileged data. JWST + HSC + MeerKAT archives are public. The benchmark target at M3 is POSEIDON / CHIMERA on WASP-39b — a 10× speedup with no spectral binning.

  1. T+0
    M1The IRSHIPPED · v0.1.0

    Typed graphs of opacity sources, atmosphere layers, instrument PSF, observational geometry. Serialization, content-addressed runs, provenance. C++20, zero runtime deps.

  2. T + 3 mo
    M2The kernelNEXT

    GPU-resident HITRAN / HITEMP / ExoMol opacity. Voigt CUDA kernel. First differentiable transmission-spectrum solver in C++/CUDA. Validate against petitRADTRANS on the WASP-39b benchmark.

  3. T+6mo
    M3The inference engine

    Amortized SBI via normalizing flows. Compare against POSEIDON / CHIMERA on public JWST spectra. Target: 10× speed, equal or better posteriors, no spectral binning.

  4. T+9mo
    M4Lensing pass

    Strong-lensing forward model in the same IR. Differentiable ray-trace through SIE / EPL profiles. Demonstrates that the substrate generalizes beyond exoplanets.

  5. T+18mo
    M5Imaging pass

    Differentiable interferometric forward model — gridder + FFT + visibility prediction. Three disjoint sub-fields running on one kernel = the substrate claim.
