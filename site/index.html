Photons ⟶ physics.

A differentiable C++ kernel for forward-modelling astrophysical observations and inverting them to posteriors. The same argus::Retrieval API recovers exoplanet atmospheric T & abundances from transmission spectra (M2/M3), lens parameters from strong-lensing image positions (M4), and source brightness from interferometric visibilities (M5) — one substrate, seven end-to-end retrieval substrate proofs.

The event Argus inverts.

A hot Jupiter transits its host star. The dip in the stellar spectrum encodes the planet's atmosphere — the data Argus compiles into composition, T-P profile, clouds.

Why a C++ kernel with autograd is non-negotiable.

10–100×
throughput penalty

Python wrappers cost an order of magnitude in the hot path. With 10⁷ forward calls per retrieval, that order of magnitude is a week on the cluster.

bit-exact
determinism

Biosignature claims need posteriors that are bit-reproducible across hardware and years. Python autograd toolchains drift; a C++ tape with explicit operators does not.

100 GB
opacity tables, on-device

HITRAN/HITEMP/ExoMol grids are 1–100 GB per molecule. Argus keeps them on the GPU across the entire retrieval — no host bounce.

∇ x
composability

The same RT primitive callable from MCMC, normalizing-flow posteriors, and gradient-based MAP — without rewriting.

2050+
vendor longevity

A 2026 telescope takes data until 2050+. The kernel that processes its photons must compile in 2050.

Python and Julia bindings live above the kernel — for retrieval scripts, agent reasoning, plotting, UI. The hot path is C++.

End-to-end in 30 lines.

What ships in examples/01_transmission_spectrum.cpp today — atmospheric retrieval shown here is one of three physics layers in the kernel (lensing in examples/05_lensing.cpp; interferometry in examples/06_interferometry.cpp).

argus@retrieval:~/examples cpp · 47 lines · gcc 15.2 · -Wall -Wpedantic -Wconversion 
// 1. Build a 40-layer isothermal H2O atmosphere.
using namespace argus;
Species h2o{"H2O", 18.015};
Atmosphere atm = isothermal(1200.0,    // T [K]
                            1.0e-6,     // P_top [bar]
                            1.0e2,      // P_bot [bar]
                            40,         // n_layers
                            h2o,
                            1.0e-3);    // VMR

// 2. Attach an opacity kernel.
// HITRAN-grade Hui-Armstrong-Wray Voigt ships from v0.3.0 — same call site.
auto opacity = std::make_shared<GreyOpacity>("H2O", 1.0e-22);

// 3. Forward model.
TransmissionModel model;
model.add_opacity(opacity);
Spectrum s = model.forward(atm, make_grid(2000.0, 4000.0, 21));

// 4. Argus IR — content-addressed reproducible runs.
ir::Graph g;
auto a = g.add(ir::NodeKind::kAtmosphere,    "atm");
auto o = g.add(ir::NodeKind::kOpacity,        "h2o_grey");
auto m = g.add(ir::NodeKind::kForwardModel,   "transmission", {a, o});
auto p = g.add(ir::NodeKind::kSpectrum,       "out", {m});

std::cout << g.content_address();      // → 845f876e00f4ea93

Mission timeline · 18 months · single workstation.

No telescope, no wet lab, no privileged data. JWST + HSC + VLA archives are public. M2/M3 (atmospheres), M4 (lensing), and M5 (interferometry) are all shipped — seven end-to-end retrieval substrate proofs run on the same kernel. The next-target benchmarks are POSEIDON / CHIMERA on WASP-39b for atmospheres, H0LiCOW quad-lens systems for lensing, and 3C 273 VLA visibilities for interferometry.

  1. T+0
    M1The IRSHIPPED · v0.1.0

    Typed graphs of opacity sources, atmosphere layers, instrument PSF, observational geometry. Serialization, content-addressed runs, provenance. C++20, zero runtime deps.

  2. T + 3 mo
    M2The kernelSHIPPED · v0.7.10

    Hydrostatic geometry, Hui-Armstrong-Wray Voigt (~1e-6 accuracy), LineListOpacity, dual-number autograd, HITRAN .par parser, TIPS partition functions, self-broadening, pressure shift, Guillot 2010 T-P, gray cloud deck, Rayleigh. Multi-physics capstone retrieval (test_atmosphere_retrieval_full) recovers (T_irr, log₁₀VMR_H₂O, log₁₀VMR_CO₂, log₁₀P_cloud) within 3σ from a noisy synthetic JWST-PRISM-shaped spectrum in 1.8 s. CUDA residency outstanding.

  3. T+6mo
    M3The inference engineSHIPPED · v0.7.9

    MCMC + emcee ensemble + autograd HMC + Retrieval API + Gelman-Rubin R̂ / ESS + CSV chain I/O + 3 prior types + posterior-predictive bands + nn primitives + Real NVP coupling + stacked NormalizingFlow + ConditionalNF for amortized SBI + reverse-mode autograd (Wengert tape) + Adam/SGD + end-to-end MLP and flow training. Two atmospheric substrate proofs: test_retrieval (MH, 1σ) and test_hmc_atmosphere (HMC end-to-end through a differentiable Voigt-line forward via Dual<T> autograd, 3σ).

  4. T+9mo
    M4Lensing passSHIPPED · v0.7.5

    SIS / SIE / NFW / external shear / CompoundLens with closed-form Kormann-Schneider-Bartelmann (SIE) and Wright-Brainerd (NFW) deflection, generic Newton image solver, lensing potential + Fermat time delays. SIE capstone recovers all 7 free params (θ_E, q, φ, lens, source) to 0.5σ via source-plane chi² and the same Argus Retrieval API used for atmospheric retrieval.

  5. T+18mo
    M5Imaging passSHIPPED · v0.7.6

    PointSource + GaussianSource + visibility predictor on snapshot or Earth-rotation UV coverage. Multi-component capstone recovers 8 params of a compact-core + extended-jet 2-Gaussian source from 210 noisy visibility components across a 5-hour Earth-rotation track via the same Retrieval API. Three disjoint sub-fields running on one kernel = the substrate claim.

What the field uses today. What Argus changes.

Three subfields. Three independent toolchains. Each is a Python wrapper around per-domain Fortran or C/C++ code with its own data plane, its own MCMC, its own posteriors. Argus replaces the kernel under all three.

ATMOSPHERIC RETRIEVAL

Today

  • TauREx · POSEIDON · CHIMERA · petitRADTRANS — Python wrappers, per-component opacity loaders
  • 10–100× Python overhead in the hot path → bin the spectrum to keep MCMC tractable
  • None expose gradients through the full forward (ExoJAX2 is the JAX exception, validating the approach)
  • One retrieval = days–weeks of cluster wall time

Argus

  • One C++20 kernel · pluggable OpacityKernel for HITRAN/HITEMP/ExoMol/neural emulators
  • ~12 ns per Voigt eval · 1.8 s for a 4-param Guillot + 3-molecule + cloud + Rayleigh retrieval at JWST-PRISM scale
  • Full forward is autograd-aware via Dual<T> · test_hmc_atmosphere proves end-to-end HMC through the Voigt physics layer
  • Bit-exact reproducible — content-addressed runs, hex-float chain CSV, zero wall-clock seeds in the kernel
STRONG LENSING

Today

  • lenstool · GLAFIC · PyAutoLens · gravlens — Python or Fortran, separate codebases per institution
  • SIE + γ + NFW are the standard ingredients but each toolchain re-implements them
  • H₀ inference (TDCOSMO / H0LiCOW) requires hand-coded Fermat-potential time-delay glue per system
  • No common IR with the spectroscopic side of the analysis pipeline

Argus

  • Same kernel as the atmospheric pass — argus::lensing namespace
  • SIS + SIE (Kormann 1994) + NFW (Wright-Brainerd 2000) + ExternalShear + CompoundLens, all closed-form and benchmarked at ≈ 30–40 ns / deflection
  • Generic Newton image solver (~1.2 ms for a 60² grid) + Fermat potential + pairwise Δτ — the H₀-cosmography observable in the standard library
  • test_sie_retrieval: 7 SIE+source params recovered to < 0.5σ via the same Retrieval API used for atmospheric inference
RADIO INTERFEROMETRY

Today

  • CASA · WSClean · AIPS — large mature stacks, Python or shell wrappers around C/C++/Fortran
  • Imaging is dominant; model-fitting (uvfit, uvmodel) is decades-old code with separate ABIs
  • Posteriors on multi-component sky models require external MCMC plumbing or per-instrument tools (eht-imaging, dynesty wrappers)

Argus

  • Same kernel — argus::interferometry namespace
  • Point + Gaussian source primitives · ~13 ns per visibility · UV-coverage snapshot + Earth-rotation track from antenna ENU positions in one call
  • test_multi_component_retrieval: 8 params (compact core + extended jet) recovered to 3σ from 210 noisy visibility components on a 5-h VLA-like track
  • Identical inference machinery as the atmospheric and lensing layers — one set of MCMC bugs to fix instead of three

The substrate is the win, not any single feature. One bug-fixed sampler, one autograd path, one PosteriorSummary — across three subfields the community currently maintains in parallel.

The substrate claim isn't qualitative.
